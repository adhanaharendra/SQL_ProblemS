# CASE , ROUND, CEIL, FLOOR, TRUNCATE

## Solution to the problem
```sql
select ProductID, Category, Price , 
    case 
      when Category = 'Electronics' then truncate(round(Price*11)/10,0)
      when Category = 'Books' then round((Price*105)/100)
      else Price
    end as AdjustedPrice
from Products;
```
### SYNTAX
```sql
CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    ELSE result
END
```
### EXAMPLE-1

```sql
SELECT price,
       CEIL(price) AS rounded_up,
       FLOOR(price) AS rounded_down,
       ROUND(price, 2) AS two_decimal
FROM products;


SELECT ROUND(5.4); -- 5
SELECT ROUND(5.7); -- 6


-- With decimal precision
SELECT ROUND(5.44, 1); -- 5.4
SELECT ROUND(5.45, 1); -- 5.5
```


### TRUNCATE
```sql
SELECT TRUNCATE(4.567, 2); -- Output: 4.56
```
